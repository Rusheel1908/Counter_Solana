# Counter Solana

My first Solana program built using **Rust, Anchor, and LiteSVM**.

## Features
- Initialize a counter
- Increment and decrement the counter
- Test program behavior using LiteSVM

## Tech Stack
- Rust
- Solana
- Anchor Framework
- LiteSVM

## Build & Test

Build the Solana program:

```bash
anchor build --tools-version v1.54 --arch v0
```

Run the Rust and LiteSVM tests:

```bash
cargo test
```

## About
This project is part of my journey into Solana development, learning how to build on-chain programs with Rust and test them using LiteSVM.
